# 🍰 Ateliê Mendes - Landing Page & Portfólio

Landing page moderna e responsiva desenvolvida para apresentação dos produtos e cardápio do Ateliê Mendes Confeitaria.

---

## 🚀 Tecnologias Utilizadas

* React
* TypeScript
* Tailwind CSS
* shadcn/ui
* Vite

---

## 📦 Como rodar o projeto localmente

1. Clone o repositório:
git clone https://github.com/jjoaosilva7/portfolio-atelie.git

2. Instale as dependências:
npm install

3. Inicie o servidor de desenvolvimento:
npm run dev
